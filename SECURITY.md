# Security Policy

## Responsible Use

- **Only scan domains you own or have explicit authorization to test.**
- This tool is intended for security assessment of infrastructure you control or have permission to evaluate.
- Unauthorized scanning of third-party systems may violate applicable laws.

## Reporting a Vulnerability

If you discover a security issue in this project, please report it privately through the [TrustLint CLI GitHub repository](https://github.com/Jonah15-sudo/trustlint-cli) security advisory page or by email.

Please do not disclose the issue publicly until it has been addressed.
