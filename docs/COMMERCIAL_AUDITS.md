# TrustLint Commercial Audits

TrustLint offers **production-grade TLS compliance audits** backed by
automated scanning and manual expert review.

## What We Audit

| Domain                    | Depth                         |
|---------------------------|-------------------------------|
| Certificate chain         | Full path validation + OCSP   |
| TLS version support       | 1.0 – 1.3, deprecated checks  |
| Cipher suite inventory    | Key exchange, auth, encryption |
| HSTS / CSP header review  | Policy gap analysis            |
| Revocation status         | OCSP responder reachability    |
| Weakness mapping          | 20‑category risk taxonomy      |

## Deliverables

1. **Automated CLI report** (JSON + Markdown) – generated by `spl-tls-analyze`
2. **Human‑audited findings** – remediation recommendations
3. **Remediation SLA** – 48‑hour re‑audit on patched endpoints
