# TrustLint Monetization Model

## Overview

TrustLint follows a tiered model that keeps the open-source CLI free and unlimited while monetizing managed services and professional deliverables.

## Tiers

| Tier | What It Is | Price | Target Audience |
|------|-----------|-------|-----------------|
| **Open-Source CLI** | `spl-tls-analyze` — run locally on any number of domains | Free | Everyone |
| **Free 5-Domain Sample** | Lead-capture service preview | Free | Prospects |
| **Paid TLS Audit Report** | Full client-ready report | From $49 | Freelancers, agencies |
| **White-Label Reports** | Branded to your agency | Custom | Agencies |
| **Monthly Monitoring** | Recurring checks, history, alerts | Custom | Businesses |

## Principles

1. **The CLI stays free and unlimited.** No artificial limits (5-domain caps, restricted output, license keys) will be added to the open-source tool. The CLI is the distribution and trust-building layer.

2. **The free 5-domain sample is a service funnel.** It is a manual/commercial preview, not a CLI restriction. Prospects submit domains and receive a lightweight summary. This builds trust and demonstrates value before purchase.

3. **Paid value = managed workflow + professional deliverables.** Customers pay for:
   - Client-ready formatted reports (PDF)
   - White-label delivery under their own brand
   - Recurring monthly monitoring with change tracking
   - Remediation guidance and priority support
   - Human review and expert context

4. **No artificial scarcity.** The 5-domain limit applies only to the free sample-report service, not to the CLI. "Unlimited domains" is never positioned as a paid feature — it is the default for the open-source tool.

5. **Hosted SaaS is not being built now.** A hosted backend, dashboard, alerts, and user accounts may come later if demand justifies it. Until then, all paid services are delivered manually or via scheduled CLI runs.

## What We Are Not Doing

- Not adding a 5-domain limit to the CLI
- Not limiting JSON or Markdown output
- Not making "unlimited domains" a paid upgrade
- Not building SaaS, dashboard, or billing yet
- Not publishing a package named `trustlint`
- Not renaming the CLI command or modules

## Future (Undefined)

- Hosted scan scheduler with history
- Email/Slack alert integrations
- Dashboard for multi-client management
- API for automated pipeline integration

These will only be built if there is clear demand and sustainable revenue to support them.
