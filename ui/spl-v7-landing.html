Pipeline

From evidence to decision in five stages

Each stage is independently monitored, auditable, and gated — ensuring that only trusted signals reach the decision layer.

01

Raw Evidence Ingestion

Collector data streams into the pipeline via Kafka topics or direct ingestion endpoints. Each datum is timestamped, sourced, and hashed for integrity verification.

KafkagRPCIntegrity Hash
02

Safe Feature Extraction

The SPL DSL compiler parses extraction rules into a sandboxed execution plan — guaranteed to terminate within bounded time and memory, with no side effects on the pipeline.

DSL CompilerSandboxedBounded
03

Online Causal Graph Learning

An incremental constraint-based learner updates the causal graph with each new evidence vector — discovering structure without ever retraining from scratch.

IncrementalConstraint-BasedOnline
04

Trust Checks & Confidence Gates

Every edge and path in the causal graph passes through corroboration, stability, independence, and intervention checks — producing per-path confidence scores.

CorroborationStabilityIndependence
05

Decision & Graph Output

Decisions are emitted with full provenance — the causal paths, confidence scores, and evidence that support them. The updated graph is published for downstream consumers.

ProvenanceGraph OutputDecision Log
